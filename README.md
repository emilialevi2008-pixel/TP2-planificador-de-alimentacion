# TP2 - Planificador Personalizable de Alimentación Semanal

**Materia:** Programación Orientada a Datos  
**Universidad:** UCA  
**Autora:** Emilia Agustina Levi  
**Lenguaje:** Python

## 1. Problema

Organizar las comidas de una semana puede resultar complicado cuando se deben considerar el presupuesto disponible, la cantidad de personas, el tiempo de preparación, las preferencias alimentarias y los objetivos nutricionales.

La planificación manual también dificulta calcular los ingredientes necesarios, estimar los costos y mantener una alimentación variada.

## 2. Usuarios

La aplicación está dirigida a personas que desean organizar sus comidas semanales de manera práctica, teniendo en cuenta sus preferencias y recursos disponibles.

## 3. Solución propuesta

Desarrollar una aplicación en Python que genere automáticamente un menú semanal personalizable, utilizando una base de datos de recetas e ingredientes.

El programa priorizará la variedad y permitirá establecer restricciones de presupuesto, tiempo de preparación e ingredientes excluidos.

## 4. Funcionalidades previstas

- Planificar desayunos, almuerzos, meriendas y cenas.
- Seleccionar qué comidas incluir durante la semana.
- Configurar el presupuesto semanal y la cantidad de personas.
- Establecer un tiempo máximo de preparación.
- Excluir ingredientes.
- Generar menús variados.
- Activar o desactivar objetivos nutricionales diarios.
- Consultar calorías, proteínas, carbohidratos y grasas aproximadas.
- Consultar ingredientes e instrucciones de preparación.
- Reemplazar comidas del menú.
- Calcular costos estimados.
- Generar una lista de compras consolidada.
- Guardar los resultados.

## 5. Datos previstos

Se utilizará una base de aproximadamente 80 recetas, con ingredientes, cantidades, unidades, categorías, tiempos de preparación e instrucciones.

Los datos estarán disponibles en formatos CSV y JSON. Se documentará su procedencia y se utilizarán valores nutricionales de referencia y precios simulados.

## 6. Alcance y limitaciones

La primera versión funcionará mediante una interfaz de consola en Python.

No incluirá una aplicación web, compras automáticas en supermercados ni recomendaciones médicas o nutricionales personalizadas.

Los costos y valores nutricionales serán aproximados.
